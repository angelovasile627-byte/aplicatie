# Aplicatie - Website Builder (Scaffold)

Acesta este scaffold-ul inițial pentru aplicația desktop (Electron + React + GrapesJS).

Quick start:
1. npm install
2. npm run start

Scop: să oferă un editor WYSIWYG de bază și un punct de pornire pentru implementarea funcționalităților (media manager, export, FTP, publish differential, storage projects).
